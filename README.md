# Система складского учета «Склад Электроники»
## 1. Назначение программы
Программа разработана для автоматизации учета товаров на складе электроники. Она позволяет сотрудникам регистрировать новые поступления, оформлять списание товаров при продаже и контролировать финансовые показатели склада в режиме реального времени. Приложение помогает избежать ошибок в расчетах и ускоряет процесс инвентаризации.

## 2. Требования к системе
### Функциональные требования:
•   **Добавление данных:** Регистрация товаров с указанием артикула, названия, категории и цены.
•   **Редактирование:** Обновление количества товара при повторных поставках.
•   **Удаление/Списание:** Уменьшение остатка при отгрузке товара с проверкой наличия.
•   **Поиск:** Фильтрация списка товаров по выбранной категории.
•   **Вывод результатов:** Отображение таблицы всех товаров и расчет общей стоимости склада.
### Нефункциональные требования:
•   **Удобство:** Простое текстовое меню для управления программой.
•   **Интерфейс:** Консольный интерфейс, не требующий установки графических библиотек.
•   **Корректность:** Обработка ошибок ввода (например, если вместо цены ввели буквы).
•   **Читаемость:** Код написан по стандартам ООП с комментариями.

## 3. Функциональные части программы (Модули)
•   **Модуль ввода данных:** Реализует взаимодействие с пользователем через консоль.
•   **Модуль обработки данных:** Содержит логику классов Product и Warehouse, методы расчета и фильтрации.
•   **Модуль хранения данных:** Использует структуру Dictionary для быстрого доступа к товарам по артикулу.
•   **Модуль вывода результатов:** Формирует наглядные таблицы и финансовые отчеты.

## 4. Особенности приложения
•   **Высокая расширяемость:** Благодаря использованию классов, в программу легко добавить сохранение в файлы (Excel/JSON).
•   **Быстрый поиск:** Использование хэш-таблиц (словари) позволяет находить товар мгновенно.
•   **Безопасность:** Реализована проверка, не позволяющая списать больше товара, чем есть на складе.
